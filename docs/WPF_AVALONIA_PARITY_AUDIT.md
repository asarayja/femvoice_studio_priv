# WPF → Avalonia parity audit (multi-agent, 2026-07-18)

Compare→adversarial-verify over 19 screen pairs. **132 confirmed gaps** (19 high / 61 medium / 52 low), 30 intentionally-deferred.

Confirmed = the verifier read the real Avalonia code and confirmed the gap. Deferred = genuinely missing but documented/expected (clinical audit trails, per-dimension DSP data, support-package/backup, import/export).
