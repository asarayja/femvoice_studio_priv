# Front Page Progress Manual Checklist

Sprint G Addendum check for the home sidebar cards:

- Start app with existing sessions.
- Check `Din progresjon` value and progress bar.
- Check `Nåværende nivå` value.
- Complete a new exercise session with a score high enough to qualify for progression.
- Return to front page and verify the progress counter and bar update.
- Complete a low-scoring session and verify the explanatory text makes the unchanged progress understandable.
- Restart app and verify the progress value and current level load from persisted user settings.
- Check empty-data state: progress should show `0/5` and an insufficient-data explanation.
- Check insufficient-data state in Norwegian text.
- Check dark mode readability for the level text, progress bar, counter, and explanation.
- Check light mode readability for the level text, progress bar, counter, and explanation.
