# ComboBox and Button Theme Visual Checklist

Use this checklist after theme changes that affect selectors, dropdowns, or buttons.

## ComboBox / DropDown

- [ ] All ComboBoxes dark mode: closed normal state is readable.
- [ ] All ComboBoxes dark mode: closed hover state is readable and has no light cyan/blue overlay over text.
- [ ] All ComboBoxes dark mode: opened dropdown state is readable.
- [ ] All ComboBoxes dark mode: normal dropdown item is readable.
- [ ] All ComboBoxes dark mode: hovered dropdown item is readable.
- [ ] All ComboBoxes dark mode: selected dropdown item is readable.
- [ ] All ComboBoxes dark mode: selected + hovered dropdown item is readable.
- [ ] All ComboBoxes dark mode: keyboard-highlighted dropdown item is readable.
- [ ] All ComboBoxes dark mode: disabled ComboBox and disabled item are readable as disabled.
- [ ] All ComboBoxes light mode: normal, hover, selected, selected + hover, keyboard-highlighted, focused, and disabled states still read correctly.

## Buttons

- [ ] Settings page buttons: normal, hover, pressed, focused, and disabled states are readable in dark mode.
- [ ] Settings page buttons: normal, hover, pressed, focused, and disabled states are readable in light mode.
- [ ] Manual adjustments page button: normal, hover, pressed, focused, and disabled states are readable in dark mode.
- [ ] Manual adjustments page button: normal, hover, pressed, focused, and disabled states are readable in light mode.
- [ ] Primary buttons: dark and light mode normal, hover, pressed, focused, and disabled states are readable.
- [ ] Secondary buttons: dark and light mode normal, hover, pressed, focused, and disabled states are readable.
- [ ] Ghost/transparent buttons: dark and light mode normal, hover, pressed, focused, and disabled states are readable.
- [ ] Danger/warning buttons: dark and light mode normal, hover, pressed, focused, and disabled states are readable.
- [ ] Icon-only buttons: dark and light mode normal, hover, pressed, focused, and disabled states are readable.

Manual visual status for this change: Needs Manual Visual Confirmation.
