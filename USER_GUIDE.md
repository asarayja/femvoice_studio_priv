# FemVoice Studio User Guide

This guide explains how to use FemVoice Studio for everyday voice practice.

## 1. First Launch

1. Start FemVoice Studio.
2. Complete the first-time setup if it appears.
3. Choose your preferred language and theme.
4. Open Settings and check that your microphone is available.
5. Run microphone calibration if requested.
6. Choose voice goal and comfort-related settings if available.

Use a quiet room and keep your microphone position consistent between sessions.

## 2. Microphone Setup

Good microphone input matters more than speaking loudly.

Before practicing:

- Select the microphone you actually plan to use.
- Avoid background noise where possible.
- Keep the microphone at a stable distance.
- Run calibration after changing microphone, room, or Windows input level.
- If the app reports low signal, move slightly closer or increase input gain.
- If the app reports clipping, lower input gain or move slightly farther away.

## 3. Main Dashboard

The dashboard is where regular practice starts.

Common actions:

1. Choose a difficulty level if needed.
2. Review the current exercise text or guidance.
3. Press Start to begin a session.
4. Speak or practice the shown exercise.
5. Watch the live chart and feedback.
6. Press Stop when finished.
7. Review any session feedback or progression update.

The pitch chart is a feedback tool. Do not use it to force your voice upward.

## 4. Exercise Guide

Use the exercise guide when you want structured practice.

Typical flow:

1. Open Exercise Guide.
2. Pick a focus area such as pitch, resonance, intonation, breathing, or practice.
3. Choose an exercise that matches your current level.
4. Read the purpose, focus cues, common mistakes, and safety notes.
5. Start the exercise.
6. Stop if you feel strain or discomfort.
7. Complete any after-session self-report if shown.

If the app suggests rest or a lower-intensity session, treat that as part of training.

## 5. SmartCoach

SmartCoach summarizes recent training and suggests a focus area.

Use it to answer:

- What should I work on today?
- Is my recent practice consistent?
- Should I maintain, progress, recover, or pause?
- Which exercise might be useful next?

SmartCoach guidance is supportive. It should not override pain, strain, or professional advice.

## 6. Resonance Analysis

The Resonance Analysis window gives more detailed visual feedback.

It may show:

- F1/F2 position.
- Formant timeline.
- Resonance score.
- Current formant values.

Use this view for inspection and learning, not for chasing exact numbers. The goal is sustainable, comfortable control.

## 7. Deep Analysis

The Analysis or Deep Analysis page shows trend charts for areas such as resonance, pitch, intonation, and health-related indicators.

Use this page to:

- Review how recent sessions compare.
- Check whether charts are moving in a useful direction.
- Inspect broad trends rather than single-frame results.
- Look for enough data before drawing conclusions.

If a chart has little or no data, complete more normal practice sessions first.

## 8. Progression

The progression view summarizes your development over time.

It may show:

- Current level.
- Overall progress.
- Training readiness.
- Recent score history.
- Areas needing more practice or recovery.

Progression may not move immediately after every session. Some indicators require enough saved data to avoid misleading feedback.

## 9. Reports

Open Reports when you want to generate a file.

Typical flow:

1. Open Reports.
2. Choose report type.
3. Choose format: PDF, CSV, or JSON.
4. Generate the report.
5. Export it to a location you choose.

Reports are summaries. Review them before sharing.

## 10. Settings

Use Settings to manage:

- Theme: light, dark, or system.
- Language.
- Voice goals.
- Accessibility preferences.
- Microphone calibration.
- Hear-own-voice monitoring.
- Backup and restore.
- Database maintenance.

Back up your data before resetting or restoring the database.

## 11. Healthy Practice Tips

- Keep sessions short at first.
- Stop if your voice feels strained.
- Use rest days and breaks.
- Do not push for higher pitch.
- Focus on comfort, resonance, clarity, and consistency.
- Use a steady microphone setup.
- Track trends over weeks, not just one session.

## 12. Troubleshooting

### No microphone input

- Check Windows microphone permissions.
- Confirm the correct microphone is selected.
- Close other apps that may be using the microphone.
- Run microphone calibration again.

### Feedback does not move

- Make sure you are in an active session.
- Speak at a normal, steady volume.
- Check microphone gain.
- Try a quieter room.

### Charts look empty

- Some charts need saved sessions before they show useful trends.
- Complete a few practice sessions and reopen the view.

### Progress does not update

- Progress indicators may need enough completed sessions.
- Check whether the app shows an insufficient-data message.
- Make sure sessions are stopped normally so they can be saved.

### Voice feels tired or strained

- Stop the session.
- Rest your voice.
- Use lower-intensity exercises next time.
- Seek professional advice if discomfort persists.

## 13. What FemVoice Studio Is Not

FemVoice Studio is not:

- A medical diagnosis tool.
- A replacement for a speech-language therapist.
- A guarantee of a specific voice result.
- A tool for forcing the voice into a range.

It is a structured practice and feedback tool.
